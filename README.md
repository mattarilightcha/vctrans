# VC翻訳（vctrans）

オンラインゲームのボイスチャット（VC）で聞こえる英語を、ゲームの画面に日本語の字幕で出します。
ボタンを押しながら日本語で話すと、英語の声にして VC へ流します。Windows 用・無料（MIT ライセンス）。

最初から **ARC Raiders** 用の設定が入っています。ほかのゲームは `profiles/` に設定を足せば使えます。

```
相手の声: ゲームの VC の音 → 声の所だけ切り出す（Silero VAD）→ 文字に（faster-whisper・PC の中で）
          → 英語だけ通す → Claude Haiku で日本語に → ゲームの画面の左下に字幕
自分の声: 録るボタン（初期はコントローラーの方向キー右）を押している間マイクを録る → 日本語の文字に
          → Claude Haiku で英語に → 英語の声（初期は Windows の声）
          → 仮想ケーブル（VB-CABLE）→ ゲームのマイク → 近くのプレイヤーとパーティへ
```

- 文字起こしは PC の中でします。**音声そのものは PC の外へ出しません**
- 訳は Anthropic の Claude API を使います。**キーは使う人が自分で入れます**（料金は使う人の Anthropic の口座から。Haiku で 1 発言およそ 0.03 円）

## 要る物

| 物 | 説明 |
|---|---|
| Windows 10 / 11（64 bit） | |
| NVIDIA の GPU（あれば） | あれば GPU で速く・正確に文字にします（large-v3-turbo）。無ければ CPU で小さいモデル（small）を使います（遅く粗くなります） |
| [VB-CABLE](https://vb-audio.com/Cable/)（無料・寄付制） | 英語の声をゲームのマイクへ流すための仮想ケーブル |
| [VB-CABLE A+B](https://vb-audio.com/Cable/)（任意・寄付で入手） | VC の声だけを聞くための 2 本目の仮想ケーブル。無くても使えます（ヘッドセットの音をまるごと聞くので、効果音やゲームの英語のアナウンスも文字にしようとします） |
| Claude の API キー | [Anthropic のコンソール](https://console.anthropic.com/settings/keys)で作ります |
| 空きの容量 | GPU のとき約 3 GB（GPU の部品 約 1.3 GB＋モデル 約 1.6 GB）、CPU のとき約 0.5 GB |

## 入れ方

1. [リリース](../../releases)から `vctrans-<版>-win64.zip` を落とし、好きな所に展開します（`C:\Program Files` の下は書き込めないので避けます）
2. VB-CABLE を入れて PC を再起動します
   - 入れると Windows の既定の音の機器が CABLE に変わることがあります。サウンドの設定でヘッドセットに戻します
3. `vctrans.exe` を起動します。操作の窓の「はじめに」のタブが開きます
   - 初回は文字起こしのモデルと GPU の部品を取ります（数分。進み具合は「はじめに」に出ます）
4. 「API キー」のタブに Claude の API キーを貼り、「保存して使う」
5. 「はじめに」の「ゲーム側の設定」のとおりに、ゲームの設定を変えます

### ARC Raiders の設定

| ゲームの設定（オーディオ） | 値 |
|---|---|
| 入力デバイス（マイク） | CABLE Output (VB-Audio Virtual Cable) |
| パーティボイスチャット | オープンマイク |
| 近接ボイスチャット | プッシュ・トゥ・トーク（キーは B） |
| ボイスチャットの出力デバイス（VB-CABLE A+B があるとき） | CABLE-A Input (VB-Audio Cable A)。操作の窓の「音の機器」→「VC を聞く」を CABLE-A Output に |
| 画面モード | ボーダーレスかウィンドウ（排他的フルスクリーンだと字幕が隠れます） |

ARC はマイク 1 本でオープンマイクにできるのが、パーティか近接の片方だけです。パーティをオープンマイク、近接を押して話す（B）にして、英語の声を流す間だけツールが B を押します。

**ツールを閉じている間はゲームにマイクが届きません。** 使わない日はゲームの入力デバイスをヘッドセットのマイクに戻します（VC の出力を CABLE-A にした場合は出力も）。

## 使い方

- **英語で話す**: 方向キー右を 0.5 秒以上押しながら日本語で話す → 離すと 2〜3 秒で英語の声が VC へ
  - 「えーと」などの言いよどみは消し、聞き違いは Claude が文脈で直します
- **相手の英語**: ゲームの画面の左下に、チャット欄のように積んで出ます（上が原文、下が訳）
- **Ctrl+Alt+O** で字幕のロックを外す（ドラッグで移動・右下の角で大きさ）、**Ctrl+Alt+P** で操作の窓、**Ctrl+Alt+Q** で終了
- コントローラーは PlayStation（DualSense・DualSense Edge・DUALSHOCK 4）と Xbox 系（XInput）を読めます。マウスのサイドボタンやキーボードのキーにもできます（操作の窓の「ボタン」→「押して決める」）

### 英語の声の作り方

| 作り方 | 説明 |
|---|---|
| Windows の声（既定） | Windows に入っている英語の声。無料・キー不要・PC の中だけ。機械っぽい声です。英語の声が無いときは Windows の設定 → 時刻と言語 → 音声 → 音声の追加 で英語（米国）を足します |
| Azure AI Speech | 自然な声。使う人の Azure のキー。無料の枠（F0）で月 50 万字まで |
| ElevenLabs | とても自然な声。使う人のキー（有料のプランが要ることがあります） |
| Piper | PC の中で作る自然寄りの声。piper.exe と声のモデルを自分で落として場所を指します |

（Python で動かす場合だけ、Edge の読み上げ（edge-tts）を「試し」で選べます。Microsoft が外のツール向けに開いている方法ではないため、配る exe には入れていません。）

## 知っておくこと

- **キーを押すこと**: 英語の声を流す間、ツールがキーボードの送るキー（ARC は B）を押します（Windows の SendInput。ゲームが前面のときだけ）。ゲームのアンチチートがこれをどう扱うかは確かめていません。**自己責任で使ってください。** 気になるなら「ボタン」のタブで流し方を「手で」にすると、ツールはキーを押さず、自分で B を押している間だけ流れます
- **外へ送る物**: 文字にした会話（相手の英語・自分の日本語・直前の数行・ゲームの用語）を Anthropic へ。読み上げに Azure・ElevenLabs を選んだら英訳の文をそこへ。音声そのものは送りません
- **PC の中だけに置く物**: 自分の録音（声の学習。`logs/voice/`）、会話の記録（`logs/`）、キー（`.env`）
- 起動中は、ふだんの声もツールがマイクから仮想ケーブルへ中継します

## ほかのゲームで使う

`profiles/generic.toml` を写して名前を変え、中身（ゲーム名・exe の名前・押して話すキー・聞き取りのヒントの語）を書き換えます。操作の窓の「はじめに」→「ゲーム」で選べます。用語集（英語 = 日本語）も同じフォルダに置けます。

## 設定・記録のファイル

| ファイル | 中身 |
|---|---|
| `config.toml` | 細かい設定（説明つき）。操作の窓で変えた値は `logs/settings.json` に入り、こちらより優先します |
| `profiles/*.toml` | ゲームごとの設定 |
| `glossary.txt` | 訳で使ってほしい語（「英語 = 日本語」） |
| `.env` | キー（ClaudeAPIKey・AzureSpeechKey・ElevenLabsKey） |
| `logs/` | 会話の記録・動作の記録・自分の録音 |
| `models/`・`runtime/` | 初回に取ったモデルと GPU の部品 |

## うまく動かないとき

- 動作の記録は `logs/vctrans-日付.log`。操作の窓の「記録のフォルダ」で開けます
- `vctrans.exe --check` で、窓も音の機器も使わずに、取得・読み上げ・文字起こしを通して `logs/check-*.txt` に結果を書きます（`--cpu` で GPU を使わない）
- 機器の名前の一覧: `vctrans.exe --devices`（Python なら `python vctrans.py --devices`）

## Python で動かす・作る

```
pip install -r requirements.txt
pythonw vctrans.py                    # または VC翻訳.pyw をダブルクリック
python -m pytest tests                # GPU も音の機器も使わないテスト
python build_tools/build.py           # dist/vctrans/ と zip を作る（pyinstaller が要る）
python build_tools/make_icon.py       # アイコンを作り直す
```
